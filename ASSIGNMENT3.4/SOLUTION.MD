## 3. Understanding the semantic tags

| HTML tag    | Purpose                                                                |
| ----------- | ---------------------------------------------------------------------- |
| `<header>`  | Contains the page title and introductory content.                      |
| `<nav>`     | Groups the navigation links.                                           |
| `<main>`    | Contains the primary content of the webpage.                           |
| `<section>` | Groups content about a particular topic.                               |
| `<article>` | Holds a self-contained piece of content, such as a course description. |
| `<aside>`   | Contains related information, such as notices.                         |
| `<footer>`  | Contains footer information.                                           |
| `alt`       | Provides a text alternative for an informative image.                  |

The updated page also uses a logical heading hierarchy: one `<h1>` for the main page title, `<h2>` for major sections, and `<h3>` for subsections.
